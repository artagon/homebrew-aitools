# Tap maintenance

- Keep formula-generated and standalone (`scripts/install-agent-skills.sh`) agent installer behavior aligned.
- Target macOS `/bin/bash` 3.2 with `set -euo pipefail`. Keep argument arrays nonempty before expansion, stop wrapper flag scans at `--`, and avoid Bash 4+ builtins (`mapfile`, `readarray`, `declare -A`, `local -n`).
- Follow `brew style` (`Homebrew/utils/shfmt.sh` separate-line `then`/`do` and `shellcheck --enable=all` `${var}` braces) across `scripts/**/*.sh`; never run `shellharden --replace` or `shfmt -bn` on `scripts/**/*.sh`.
- Use fully qualified `<tap>/<name>` (`artagon/aitools/<name>`, with `--cask` for casks) names in `caveats` and installation examples.
- Bump `revision` when changing installed files without an upstream version bump, and bump all compile-time dependents together when a shared grammar or source dependency changes; see [Java grammar patch](docs/agent-context.md#java-grammar-patch).
- Give every formula a direct `livecheck` block and keep every `url "..."` literal-versioned (never `#{version}`) followed immediately by `sha256 "<64-hex>"` (or `version "..."` then `sha256 "<64-hex>"` only when Homebrew cannot infer the version from `url`) with no trailing comment (`scripts/autobump.sh`).
- Disable upstream startup update checks, telemetry, analytics, and unsolicited cloud or paid-API routing in builds and wrappers, bind local servers/collectors to loopback (`127.0.0.1`) by default, run `chmod 0755` on bare binaries staged into `libexec/`, block in-place self-updaters (`exit 2`), and warn against self-updaters in `caveats`; see [Maintenance context](docs/agent-context.md).
- For macOS casks (`Casks/*.rb`), use Homebrew 5.x `postflight_steps` (never deprecated `postflight`) with Bash 3.2 `run "/bin/bash"`, omit `auto_updates true` when disabling Sparkle/in-app auto-updates, disable auto-updates and app telemetry by default, and expose fail-closed install overrides exclusively via `HOMEBREW_<CASK>_*` / `HOMEBREW_AITOOLS_*` env flags; see [Cask hardening & install flags](docs/agent-context.md#cask-hardening--install-flags).
- For cask LaunchServices default-handler registration (`duti`), probe at most one canonical UTI, check `duti -d` first for idempotency (never loop or batch `duti -s` across UTIs or extensions), skip when `CI` is truthy unless explicitly overridden, and keep `bats --tap tests/cask_postflight_defaults.bats` passing across `/bin/bash` 3.2 and Bash 5+ whenever changing cask `postflight_steps`.
- Declare `license :cannot_represent` and run `prefix.install "LICENSE"` when an upstream license adds a custom non-SPDX rider.
- Declare `conflicts_with` (or `conflicts_with cask:`) only when a differently named formula or cask conflicts, never on same-named formulae or casks across taps.
- Land formula changes through `publish.yml` (`brew pr-pull`), never a direct merge, and keep `.github/workflows/sign-bottles.yml@refs/heads/main` as the sole OIDC signing workflow binding both `--` and `-` bottle subjects; see [Bottles](docs/agent-context.md#bottles) and [Build provenance](docs/agent-context.md#build-provenance).
- Exercise both installer entrypoints in isolated homes, and run `bats --tap tests/verify_provenance.bats` across `/bin/bash` 3.2 and Bash 5+ when changing provenance scripts, workflows, or bottle conventions.
- Never activate hooks or modify live agent, shell, dotfile (`~/.config/*`, `~/.hammerspoon`), Homebrew trust (`~/.homebrew/trust.json`), or Sigstore (`~/.sigstore`) configuration during installs or tests (cask `postflight_steps` may write only the app's own `UserDefaults` and guarded single-UTI LaunchServices defaults, opt-out via `HOMEBREW_*_SKIP_DEFAULTS=1`).
- Run `ast-grep test --config sgconfig.yml` and `ast-grep scan --config sgconfig.yml . .github/workflows` after changing formulae, shell scripts, workflows, or rules; see [ast-grep checks](docs/ast-grep.md).
