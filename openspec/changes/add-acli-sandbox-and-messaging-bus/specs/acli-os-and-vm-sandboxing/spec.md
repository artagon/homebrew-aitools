# Spec Delta

## Purpose

Defines the global default host OS kernel sandbox (`--isolation os-sandbox`) with default-deny host reads, terminal-node path denial, per-pane immutable `<ACLI_RUN_DIR>/ca/pane-<pane_id>-ca-bundle.pem`, per-tier zero-exfiltration telemetry channels (`telem.sock`, dual-stack macOS TCP SBPL `localhost:<aclid_otlp_port>`, and `--vm` chunked `vsock:5050`), `same-sandbox` signaling, minimal 10-service Mach allowlist, Linux Supervised userns `overlayfs`/`fuse-overlayfs` B4 diff gate with in-place mid-session promotion retaining `upper` until pane exit, direct `openat2`/`O_NOFOLLOW_ANY`-verified RO `/workspace/.beads`, expanded B4 set (including `.beads/**`, `.beads.gate.lock*`, `.acli.toml`, absent Git includes, and indirect `direnv`/`mise`), closed `sys_git` allowlist + caller write-mode gate, monotonic `sys_spawn`, strict `--mode yolo` shared warm `libkrun >= 1.19.8` VM, RFC 3986 Mode A/B proxies with streaming TTFT/token/`429` telemetry, 4-zone MCP firewall, canonical non-overridable `~/.local/share/acli/workspace-locks/` (`promotion_mutex -> registry_epoch_mutex -> .owner state_mutex`), authoritative `outbox.db.acli_store_epoch` (with `store-epoch.json` RO mirror), and single-flight 4-barrier `fchmod`/`fsync` diff-promotion gate emitting `O(|modified|)` `file_diffs`.
