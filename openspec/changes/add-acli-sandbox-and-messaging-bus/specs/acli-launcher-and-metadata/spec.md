# Spec Delta

## Purpose

Defines the fast three-binary Rust AI CLI launcher (`acli`, `aclid`, `acli-shim`), complete 8-state `isatty(0..2)` Supervised Launch versus Fast-Exec Launch table (zero terminal fds outside PTY relay, declared pass-through fd non-aliasing, allowlist outbound VT filter, scoped `SIGHUP`), canonical nine-CLI option/mode (`--bead-engine auto|br|bd`)/environment/OTLP/hook-trap/authentication compiler, `< 3 ms` `acli hook emit [--drain]`, `acli telemetry status|flush|doctor|export`, `acli pane release <pane_id>`, multicall `argv[0]` shims, Ed25519-signed `ACLIIDX1` metadata (`stdio_env_mode`, hook dialects/timeouts, composer line-reset) with file+directory `T0`/`T2`/Merkle pinning, safe host Git inspection, canonical `project_key`, `acli daemon install`, deterministic exit codes with `44` closed canonical subreasons, and progressive-disclosure self-documentation.

## ADDED Requirements

### Requirement: Three-Binary Privilege Separation and Complete Eight-State Supervised vs Fast-Exec Launch
The suite SHALL split across unentitled `acli`, `aclid`, and hypervisor `acli-shim`, disambiguating the closed reserved subcommand noun set (`auth`, `mcp`, `msg`, `bus`, `vm`, `daemon`, `pane`, `hook`, `telemetry`, `git`, `spawn`, `promote`, `discard`, `approve`, `ps`, `explain`, `describe`, `schema`, `self-update`, `update`) from provider launches. Children MUST hold **zero** host TTY fds outside PTY relay / un-relayed host, passing caller fds solely via repeatable `--pass-fd <N>` (`N >= 3`).

#### Scenario: Complete eight-state isatty(0..2) launch matrix, --pass-fd non-aliasing, reserved nouns, and scoped SIGHUP handling
- **WHEN** a user runs (a) interactive `acli claude` (`isatty(0) && isatty(1)`: states `111`/`110`), (b) ANY of the 5 partial-TTY combinations `(isatty(0) || isatty(1) || isatty(2)) && !(isatty(0) && isatty(1))` (`001, 010, 011, 100, 101` — including `acli claude -p x | jq`, `acli claude -p x > out.log 2>&1`, `v=$(acli claude -p x)`, and `cat prompt | acli claude -p`), (c) pure non-TTY `000` with any Supervised flag (`--timeout`, `--vm`, `--otel-wrap`, Linux `os-sandbox`, etc.) or session-leader fallback, (d) pure non-TTY `000` macOS `acli kimi -p "..." </dev/null >out.log 2>&1` with zero Supervised flags (including leaked `3>/dev/tty` or undeclared `/dev/./fd/63`, `/proc/thread-self/fd/63`, `--file=/proc/<pid>/fd/63`), or (e) `--isolation host` without Supervised flags (`--timeout`, `--otel-wrap`, `--format canonical-jsonl`)
- **THEN** `acli`'s `lexopt` parser disambiguates the closed reserved top-level subcommand noun set (`auth`, `mcp`, `msg`, `bus`, `vm`, `daemon`, `pane`, `hook`, `telemetry`, `git`, `spawn`, `promote`, `discard`, `approve`, `ps`, `explain`, `describe`, `schema`, `self-update`, `update` — with `self-update`/`update` exiting `2` natively in Rust directing to `brew upgrade artagon/aitools/acli`) from provider invocations; **Supervised Launch** overrides **Fast-Exec** on any TTY fd outside un-relayed `--isolation host`, `--vm`, `--mode yolo`, `--timeout`, `--format canonical-jsonl`, `--otel-wrap`, `acli auth login`, stdin `SecretRef`, Linux `os-sandbox`, or session-leader fallback; pre-`sandbox_init`/`execve` in BOTH Supervised and Fast-Exec modes, `acli` accepts explicit caller pass-through fds strictly via repeatable **`--pass-fd <N>`** (`N >= 3`, verified open via `fcntl(F_GETFD)`), allocates all `acli`-owned internal descriptors (pipes, lifeline, or `acli`-injected `qwen --otel-wrap --json-fd <internal_fd>`) strictly **above `max(2, max_declared_caller_fd)`** so caller descriptors NEVER alias `acli` internal descriptors, closes all undeclared inherited fds via Linux `close_range` (`/proc/self/fd` fallback) or macOS `/dev/fd` scan setting `FD_CLOEXEC` / `close()` (never calling non-existent macOS `closefrom`/`close_range`), and normalizes lexical, repeated-slash, symlink, and joined `--opt=<path>` fd aliases (`/dev/fd/N`, `//dev/fd/N`, `/dev/./fd/N`, `/proc/self/fd/N`, `/proc/thread-self/fd/N`, `/proc/<pid>/fd/N`) before rejecting any undeclared `N` with `exit 66` (`E66:fd_arg_unsupported`); (a) runs Interactive Supervised PTY Relay (`< 3 MiB` PTY relay where the child calls `setsid()` + `ioctl(TIOCSCTTY)` on `PANE_SLAVE_TTY`, `pty.sock`, `fd 2` attached to PTY slave in state `111` or redirected file in state `110`, allowlist outbound VT filter from `specs/acli-mux-herdr-ntm/spec.md` permitting base64-set `OSC 52` ONLY when host-invoked `--allow-osc52` is set outside `--mode yolo`/`sys_spawn`, stamping `@acli_provider` and `ACLI_LOGICAL_PROVIDER`)
- **AND** (b) runs Partially Redirected Terminal Supervised Pump: `acli` replaces EVERY terminal-backed fd among `{0, 1, 2}` with an OS pipe (pumping host `stdin` -> child `stdin` pipe, or binding child `fd 0` to `/dev/null` for non-interactive `-p` runs, and pumping child `stdout`/`stderr` pipes through the allowlist outbound VT filter whenever the corresponding host fd is a TTY, so writing `OSC 52` or `DCS` to `fd 0`, `fd 1`, or `fd 2` never reaches the terminal unfiltered), calls `setsid()` in the forked child before `sandbox_init_with_parameters` (`open("/dev/tty", O_RDWR) == -1 (ENXIO)` — scoped strictly to non-PTY modes `(b)`–`(d)`), and leaves `1` `acli` supervisor process with an active `SIGHUP`/`SIGTERM` drain handler and child `SIGHUP` reset to `SIG_DFL` pre-`execve`
- **AND** (c) runs Pure Non-TTY Supervised Pipe calling `setsid()` in the forked child before `sandbox_init_with_parameters` (verifying `open("/dev/tty", O_RDWR|O_CLOEXEC) == -1 (ENXIO)`) with active `SIGHUP`/`SIGTERM` forwarding (`tmux kill-pane` `SIGHUP` terminates Supervised modes `(a)`–`(c)` cleanly) and `--timeout` exit `124`
- **AND** (d) runs macOS Fast-Exec (`0` surviving `acli` processes): checks `getsid(0) == getpid()` first (transitioning session leaders cleanly to waiting Supervised fork (c)); otherwise ignores `SIGHUP` **ONLY** around `ioctl(open("/dev/tty", O_RDWR|O_NOCTTY|O_CLOEXEC), TIOCNOTTY)` + `close()`, **immediately restores the prior `SIGHUP` disposition (`SIG_DFL`) before `sandbox_init_with_parameters` and `execve`**, and verifies `open("/dev/tty", O_RDWR|O_CLOEXEC) == -1 (ENXIO)` (else `exit 71` `E71:tty_detach_failed`); (e) runs un-relayed direct `execvp` (`< 1 ms` compute, `0` surviving `acli` processes, `#{pane_current_command}` = `<provider>`/`node`)

### Requirement: Multicall argv[0] Shims Without Ambient Bypass Escapes
`acli` SHALL support multicall invocation via provider-named symlinks (`claude`, `codex`, `agy`, `copilot`, `kimi`, `grok`, `opencode`, `gemini`, `qwen`) using `fstat` `(st_dev, st_ino)` self-skipping and a bounded hop counter (`ACLI_SHIM_DEPTH <= 4`). `acli` MUST NOT honor `ACLI_BYPASS` to skip sandboxing, pinning, or translation.

#### Scenario: Multicall shim resolves underlying binary by inode and preserves logical arg0
- **WHEN** a user or multiplexer invokes a symlink `claude -> acli` on `PATH`
- **THEN** `acli` skips every `PATH` candidate whose `fstat` `(st_dev, st_ino)` equals `current_exe()` or resides in `<shim_dir>`, executes the verified target binary (`fexecve` on Linux; verified `realpath` on macOS), and sets `.arg0("claude")`
- **AND** if no non-self target binary exists on `PATH`, `acli` exits with code `127`

#### Scenario: Ambient ACLI_BYPASS=1 rejected and recursive shim loop fails closed
- **WHEN** a child sub-agent or script sets `ACLI_BYPASS=1` before invoking a multicall shim, or a misconfigured symlink chain exceeds `ACLI_SHIM_DEPTH > 4`
- **THEN** `acli` ignores and scrubs `ACLI_BYPASS` (never disabling `os-sandbox`, pinning, or credential scrubbing)
- **AND** exceeding `ACLI_SHIM_DEPTH > 4` aborts fail-closed with exit code `78` (`E78:shim_depth_exceeded`)

### Requirement: Signed Diff-Only Version Metadata and Zero-Copy ACLIIDX1 Index
Provider CLI metadata SHALL live in Git as diff-only `configs/cli-meta/<cli>/{baseline.toml,versions.jsonl}` (recording `stdio_env_mode`, hook dialects/`supports_hook_context_injection`/timeouts, telemetry rules, and non-`0x03` composer line-reset) and compile into an Ed25519-signed (`ACLISIG1`) fixed-stride `ACLIIDX1` binary index embedded via `include_bytes!` with an optional `0600` `$HOME/.cache/acli/index.bin` `mmap` overlay verified by embedded key or host-keyring HMAC.

#### Scenario: Zero-copy signed ACLIIDX1 lookup and atomic cache compilation

### Requirement: File-and-Directory Manifest T0 Cache and Cryptographic Binary Pinning

#### Scenario: In-place JS edit and injected extensionless sibling file both trigger T0 miss and exit 77

#### Scenario: T2 CodeDirectory digest and T4 cold-path upgrade gate fail closed
