# Spec Delta

## Purpose

Defines the hardened `artagon/aitools` Homebrew formulae (`agent-mail` `0.3.41` `revision 1`, `nats` `0.5.2` `revision 1`, `nats-server` `2.15.3`, `br` `0.7.6` `revision 1`, `bd` `1.3.4` `revision 2`, pure-Rust `acli`, and companion `phoenix-cli` `1.22.1` / `arize-phoenix` `21.1.0` / `langfuse-cli` `1.3.1` / `openlit` `2.1.1` / `mlflow` `3.18.0` / optional `artagon-harness-eval` interop) targeting `Homebrew >= 7.0.5` source builds (`std_cargo_fetch_args`, cold Cargo/Go cache gate; separate bottle-pour compatibility), `/bin/bash` 3.2 runtime wrappers (`NATS_CONTEXT`, `br upgrade` block, `BD_DISABLE_EVENT_FLUSH=1` + `DOLT_METRICS_DISABLED=1`, `bin/aclid` `ACLI_SHIM_PATH`, and standalone Stage-1 `libexec/bin/nats-bind-preflight`) with direct zero-Bash `bin/acli` symlink, offline `def fetch` + `deny_network_access!`, platform-accurate dependencies, exact `CodeDirectory` `Identifier` + binary slot 5/7 signing verification, tap script extensions, `ast-grep` rules, and per-artifact/platform `versions/aitools-lock.json` zero-Linux-builder (`--option builders ''`) Nix parity.

## ADDED Requirements

### Requirement: Hardened Formula/agent-mail.rb (0.3.41 revision 1) Across Both Entrypoints
`Formula/agent-mail.rb` (`0.3.41`) MUST bump to `revision 1` preserving literal-versioned per-platform URLs and SHA-256 digests, stage bare binaries into `libexec/` (`chmod 0755`), wrap BOTH `bin/am` and `bin/mcp-agent-mail` in `/bin/bash` 3.2 blocking `self-update` and `update` (`exit 2`), default HTTP serving to `127.0.0.1` with telemetry off, and stage `pkgshare/skills/agent-mail/SKILL.md` passively.

#### Scenario: Both bin/am and bin/mcp-agent-mail block self-update and update while preserving upgrade
- **WHEN** a user runs `am self-update`, `am update`, `am -v self-update`, or `AM_INTERFACE_MODE=cli mcp-agent-mail self-update` versus `am upgrade`, `am help self-update`, or `am -- --self-update`
- **THEN** both `/bin/bash` 3.2 wrappers (`set -euo pipefail`, state-machine scan stopping at `--`, nonempty array expansion) exit with code `2` for `self-update` and `update` and direct users to `brew upgrade artagon/aitools/agent-mail`
- **AND** `am upgrade`, `am help self-update`, and server modes run normally with `HTTP_HOST=127.0.0.1` and `DO_NOT_TRACK=1`, preserving `license :cannot_represent`, `prefix/LICENSE`, and `pkgshare/skills/agent-mail/SKILL.md` with zero dotfile writes

### Requirement: Hardened Stage-1 Formula/nats-server.rb (2.15.3) with Self-Contained Bind Preflight

#### Scenario: Field-independent CLI precedence, Go flag.FlagSet normalization, and per-field ambiguity exit 78
- **WHEN** `bin/nats-server` runs standalone in Stage 1 (with `acli` absent from `PATH`) under (a) port-only CLI `-p <free_port>` (or `--p`, `-port`, `--port`) with a hostless config or no config, (b) address-only CLI (`-a`/`--a`/`-addr`/`--addr`/`-net`/`--net` in split or `=` form, including repeated aliases and `--`), (c) top-level config (including `include`s, case-insensitively) setting multiple directives for the same effective field (`host`+`net`, `listen`+`host`/`net`, or `listen`+`port`), OR (d) valid top-level `host`+`port` with nested `leafnodes`/`cluster`/`gateway`/`websocket`/`mqtt` blocks
- **THEN** `libexec/bin/nats-bind-preflight` normalizes BOTH single-hyphen and double-hyphen Go `flag.FlagSet` prefixes (`a`, `addr`, `net`, `p`, `port`, `c`, `config` in split and `=` forms, honoring non-target flag value consumption and last-flag-wins repeat order, stopping at `--`) and resolves client `address` and `port` **independently** (`explicit CLI flag > validated single-source top-level config > 127.0.0.1 / 4222`), rejecting any empty/whitespace-only effective CLI bind address (`-a ""`, `--addr=""`, `--net=""`) prior to `exec` with `exit 78` (`E78:ambiguous_nats_bind`), treating empty config `host: ""` as hostless, and inserting generated flags inside the parsed option segment before `--` / positional args:
  - Inject `--addr 127.0.0.1` iff NEITHER a non-empty explicit CLI address flag NOR a non-empty validated top-level config address (`host`, `net`, or host-bearing `listen`) is present — so case (a) `nats-server -p <free_port> -c hostless.conf` (and `host: ""`) binds strictly one client listener on `127.0.0.1:<free_port>` (NEVER `0.0.0.0` or `[::]`)
  - Inject `-p 4222` iff NEITHER an explicit CLI port flag NOR a validated top-level config port (`port` or port-bearing `listen`) is present — suppressing generated `--addr` ONLY on CLI/config address and generated `-p` ONLY on CLI/config port
  - Exit `78` (`E78:ambiguous_nats_bind`) on case (c) duplicate per-field setters while preserving valid `host`+`port` and isolated nested listener blocks in case (d)
- **AND** Homebrew installs zero `service do` definitions, JetStream `--store_dir` defaults to `${XDG_STATE_HOME:-$HOME/.local/state}/nats/jetstream`, and `ast-grep` enforces `"nats-server"` in `rules/ruby/formula-conflicts-same-name.yml`
