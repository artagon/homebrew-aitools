# Spec Delta

## Purpose

Defines the three-plane inter-agent coordination bus (`NATS v2.15.3`, `AgentMail v0.3.41`, and host-authoritative dual-engine `Beads`: `br v0.7.6` SQLite/JSONL + `bd v1.3.4` embedded Dolt epics & sync), explicit `ACLI_INSTANCE` isolation anchored to fixed non-overridable `$HOME/.local/share/acli/workspace-locks/`, authoritative single-DB `outbox.db.acli_store_epoch` (with `store-epoch.json` RO mirror) + `continuity_unproved` latch + `created_ts_us` immutable `msg_ref` + durable `acli_obj_grants` (`PROVISIONAL`/`LIVE`/`QUARANTINED_SCHEMA`), pre-engine `PENDING_INTENT` + `last_enqueued_bead_state` + dedicated `ACLI_BEAD_EVENTS_<proj_hash>`, brokered allowlist-only nine-tool `acli-bus-rpc/v1` (+ CLI-only `sys_git`/`sys_spawn`), W3C `traceparent`/`SpanLink` propagation, `ACLIIDX1`-driven `stdio` `acli mcp sync`, and the ten-verb `acli msg` / nine-tool `acli mcp serve-bus` surface.
